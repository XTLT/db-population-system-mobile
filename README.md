# 人口通 - 移动端（Android App）

人口通系统的移动端仓库（Flutter App），通过 HTTPS（支持 IPv6）连接服务端，随时随地查询人口、家庭、补贴与统计数据，并支持在手机上编辑人员、管理学生、查看报表。

> 本仓库由原 `db-population-system` 拆分而来；服务端与 Web 前端在 `db-population-system-server`，桌面端在 `db-population-system-desktop`。

## 功能详解

### 首页（底部导航三大模块）

**① 人员查询**
- 人员列表：按姓名搜索，支持多选
- **批量编辑**：勾选多人后一次修改——是否去世 / 低保类别 / 残疾情况 / 残疾等级 / 贫困户类型 / 计生情况
- 添加人员、查看详情、高级搜索入口

**② 学生管理**
- 学生列表：按姓名/就读信息检索
- 学生详情：学校、年级、入学/毕业日期等就读信息
- 学生编辑：在线修改就读信息（学校、年级、入学时间、毕业时间）

**③ 数据统计**
- 统计卡片：人口、补贴、社保卡、林地面积等核心指标总览
- **统计图表**：趋势图（时间序列变化）、分布图（构成占比）、雷达图（多维度对比）

### 人员 / 家庭

**人员详情**：展示全部字段——姓名、身份证号、户号、地址、小组、与户主关系、年龄、电话、是否死亡、社保卡 1/2/3（**多来源标注**：最多展示 3 个不同社保卡，每个卡显示导入来源）、残疾情况（**类型 + 等级**）、低保类别、脱贫/监测类型、计生情况、特困供养（含供养类型）、备注。

**添加 / 编辑成员**字段：

| 分组 | 字段 |
|---|---|
| 基本信息 | 身份证号 *（自动校验格式）、姓名 *、户号、**与户主关系**（45 项标准下拉：公安部户口簿规范 + GB 4761-1984 家庭关系代码 + 民法典近亲属；存量非标准值自动并入选项兜底不丢失）、是否死亡 |
| 联系信息 | 电话、地址、小组 |
| 社会保障 | 脱贫户或监测户（脱贫户/脱贫不稳定户/突发严重困难户/边缘易致贫户）、残疾（是 → 展开残疾类型 7 类 + 残疾等级 4 级）、低保（是/否/低保边缘家庭/特困家庭）、是否计生家庭、是否特困供养（是 → 供养类型：集中供养/散居特困） |
| 其他 | 备注 |

**智能带出**：新增家庭成员时自动带出同户的地址与小组（已有同户成员时），无需重复填写。

**户主规则**（服务端统一处理，三端生效）：
- **每户唯一户主**：添加"户主"关系时自动校验，已有户主则拒绝
- **换户主整户关系重建**：把某人改为户主，系统自动重算全户关系（旧户主变父/母、其他子女按年龄变兄/弟/姐/妹等，无法确定的保持原值）

**高级搜索**：多条件组合筛选（姓名、户号、地址、残疾、低保、脱贫类型等），保存常用搜索条件。

### 补贴查询

- **地力补贴**查询（每年一个值）
- **养老保险**查询
- **低保发放**查询（费款所属期、家庭保障总金额、最低生活基本保障金、特殊困难补助金等明细）
- **特困发放**查询
- **残疾人护理补贴**查询
- **高龄补贴**查询
- **月度发放**查询（按月份汇总各补贴）

### 自定义报表

- **报表构建器**：自定义选择字段/条件生成报表
- **报表列表**：已保存报表管理
- **报表查看**：在线查看，支持导出 **PDF** 分享/打印

### 通知中心

- 通知列表：服务端下发的通知消息
- **未读角标**：首页铃铛显示未读数
- **发送通知**：管理员向用户/全员发送通知

### 数据与同步

- **数据管理**：查看/清理本地数据
- **备份 / 恢复**：本地数据备份与恢复
- **离线数据**：弱网/离线时缓存数据，联网后使用
- **同步**：数据同步状态指示，**冲突解决**页面处理同步冲突

### 照片管理

- 人员照片上传、查看、管理

### 用户管理（管理员）

- 用户列表、新增用户、角色权限管理

### 设置

- 服务器地址配置（支持 IPv6）
- **主题自定义**：界面主题/颜色个性化
- 操作日志查看
- 搜索历史、常用筛选记忆
- 新功能引导提示（tooltip）

### 更新与安全

- **自动更新**：检查更新（服务器主源 + SHA256 强校验）→ 下载 → 安装
- **HTTPS 连接服务端**（支持 IPv6），**证书扎钉（Certificate Pinning）** 验证服务端身份，防中间人

## 环境要求

- Flutter SDK（≥ 3.x）
- Android SDK（构建 APK）

## 构建（android-arm64 APK）

```bash
./build_mobile.sh check      # 检查 Flutter 环境
./build_mobile.sh config https://你的域名:5000   # 配置 API 地址
./build_mobile.sh build release --target-platform android-arm64   # 构建正式版 APK
```

直接构建（推荐 arm64，体积小、兼容主流安卓手机）：

```bash
flutter build apk --release --target-platform android-arm64
```

构建产物：`build/app/outputs/flutter-apk/app-release.apk`

## 目录结构

```
lib/                    # Flutter 代码（页面 / API 客户端 / 配置）
  config/app_config.dart  # API 地址配置
  pages/                  # 各功能页面（人员/学生/补贴/统计/报表/通知/设置等）
  services/               # API 请求与业务服务（更新/同步/离线/通知/照片/PDF 等）
  constants/              # 公共常量（如关系标准列表）
assets/certs/           # 服务端证书（证书扎钉用）
android/                # Android 工程
ios/                    # iOS 工程
docs/                   # 开发指南
```

## 证书说明

移动端使用证书扎钉（Certificate Pinning）验证服务端身份。更换服务端证书后，需将新的 `server.crt` 复制到 `assets/certs/` 并重新构建。

详见 `docs/移动端开发指南.md` 与 `docs/Android签名配置指南.md`。
